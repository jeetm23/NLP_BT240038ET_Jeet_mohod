    About This Project

    Project Overview

    This project uses Natural Language Processing and Machine Learning to classify SMS messages as Spam or Ham. Text preprocessing and TF-IDF feature extraction are used before classification using a Naive Bayes model.

    Tech Stack

    • Python 3 — Core programming language
    • scikit-learn — ML model & TF-IDF
    • NLTK — Text preprocessing
    • Pandas — Data manipulation
    • HTML/CSS/JS — Frontend UI

    Dataset

    The model is trained on the UCI SMS Spam Collection dataset containing 5,572 labeled SMS messages (4,827 ham + 747 spam). The dataset is publicly available for research purposes.
